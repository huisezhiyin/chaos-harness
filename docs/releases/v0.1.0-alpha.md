# v0.1.0-alpha 发布说明草稿

状态：脱敏源码候选，尚未发布标签或 Release。

Chaos Harness 是通过 OpenCode 操作代码仓库的实验性 Harness，提供任务与 Attempt 记录、完成证据检查、有界恢复，以及 Host/工具临时环境分离。

本候选包含验收时限参数透传和缺失临时目录恢复。默认日常验收时限保持不变；专用评测可显式选择时限。真实 Host 本地固定响应已验证删除临时目录后下一条命令仍可执行。

当前试用范围：macOS、Node.js 22、pnpm 11.6.0、OpenCode 1.18.27；主验证模型为 DashScope Qwen。安装见 [PREVIEW.md](../../PREVIEW.md)，首次使用请准备自己的模型配置并选择可检查的小任务。

最近两批 8 个不同维护任务中，6 个端到端通过。两批运行版本不同，另外两条失败原始记录保留；这不是统一 benchmark 成功率，也不证明相对优势。

已知限制：外部首次试用反馈未收集；日常入口没有任意任务的独立业务验收器；运行环境检查不是 OS 沙箱；Linux、Windows 和 Codex fallback 不属于本预览验证范围。需要人工检查最终 diff 和测试结果。


源码仓库：[huisezhiyin/chaos-harness](https://github.com/huisezhiyin/chaos-harness)。发布前确认最终提交的 [CI](https://github.com/huisezhiyin/chaos-harness/actions/workflows/preview.yml) 通过。
