# Alpha 首次试用

目标是确认外部开发者能按文档独立跑通，记录卡点，不要求完成复杂 benchmark。计划邀请 2–3 位试用者，尚未收集到外部完成证据。

1. 按 [安装说明](../PREVIEW.md) 获取候选，记录提交 SHA、macOS/Node/pnpm/OpenCode 版本。
2. 执行基础自检；可选原生 Host 自检只使用本地固定响应，不调用远程模型。
3. 用自己的服务配置执行 `--check-profile`。密钥不要提交到仓库或问题报告。
4. 选择一个你熟悉、可以检查结果的小仓库，在干净 Git 状态开始。提出一个边界清楚的任务，例如给一个函数增加空值和边界条件测试，不修改其他行为。
5. 观察任务是否结束、是否需要你介入。检查 diff，在自己的终端运行项目测试，确认是否符合原需求。
6. 用下方模板提交经过脱敏的反馈。遇到失败保留原记录，不必反复重跑。

- 环境版本（macOS / Node / pnpm / OpenCode）：

- 安装与自检：通过 / 失败，卡在哪一步：
- 任务描述及预期结果（可匿名化）：
- 是否独立跑通：是 / 否；人工介入次数与原因：
- 最终状态、耗时、自己运行测试的结果：
- diff 是否符合需求，有无无关改动：
- 最影响使用的一处问题：

仅提交必要、脱敏的错误摘要。不要贴完整对话、工作仓库内容、个人配置或原始运行日志。

维护者收到真实反馈后逐项登记；本机安装演练和自动化测试不计为外部试用完成。
